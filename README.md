# ⚡ Neural Bus Switcher Visualizer

An interactive, high-speed 2D canvas visualization simulating dynamic data routing, token switching, and continuous neural network weight transfers between vertical bus architectures.

## 🌟 Visual Overview

This project simulates the internal high-speed switching mechanics of modern AI supercomputers and matrix routing engines:

* **Vertical Channels**: Represent dedicated bus channels or neural hidden layers.
* **Smooth Interpolated Routing**: Connection bridges smoothly slide and bend up and down across vertical channels using continuous cubic Bézier curves instead of abrupt jumps.
* **Bi-Directional Packet Flow**: High-frequency data pulses travel across dynamic connections, changing color spectrums based on directional trajectory (Upward vs. Downward routing).

## 🛠️ Features & Controls

* **Zero Dependencies**: Built entirely with plain HTML5 Canvas and Vanilla JavaScript.
* **Fully Responsive**: Dynamically scales to fit any display resolution or aspect ratio.
* **Interactive Control HUD**:
  * **SWITCH SPEED**: Adjusts the gliding velocity and morphing frequency of switching connection lines.
  * **BAR COLUMNS**: Dynamically scales the density of vertical channels and active connection buses in real time.
